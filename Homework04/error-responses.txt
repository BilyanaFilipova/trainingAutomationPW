HTTP Error Responses

1. 4xx Response – 401 Unauthorized

When: Open the API endpoint directly in a new browser tab without an authenticated session.
I accessed the /api/v1/auth/me endpoint directly in a new browser tab without an access token.
==>The server returned HTTP 401 Unauthorized because authentication was required, but no access token was provided.

Request URL: http://localhost:3001/api/v1/auth/me

Request Method: GET

Status Code: 401 Unauthorized

Response:

{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "Access token required"
  }
}
